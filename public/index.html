playwright-e2e-mcp

MCP server for running, debugging and inspecting Playwright end-to-end tests.

● Endpoint is live:

https://playwright-e2e-mcp.vercel.app/api/mcp

It speaks MCP Streamable HTTP and exposes the same eight tools as the stdio server:

  • run-test, get-failure, list-tests
  • inspect-page, validate-selector
  • generate-e2e-test, compare-visual-state, diagnose-flaky

Verify it with a handshake:

curl -X POST https://playwright-e2e-mcp.vercel.app/api/mcp \
  -H 'content-type: application/json' \
  -H 'accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-06-18","capabilities":{},"clientInfo":{"name":"curl","version":"1.0"}}}'

This hosted endpoint is for clients that only accept remote connectors (ChatGPT custom connectors, remote MCP clients). Tools that need a browser or a local project run against the files in this deployment and will say so when they cannot.
