playwright-e2e-mcp has moved
This repository is no longer maintained. playwright-e2e-mcp now lives at github.com/xsignon-secure/E2E.

The latest release is 0.4.2. To set it up in your project:

npx -y playwright-e2e-mcp init
The npm package name is unchanged, so existing installs keep working; run the command above (or npm install -D playwright-e2e-mcp@latest) to pick up the newest version.

Issues, pull requests, releases and the .mcpb Claude Desktop bundle are all at the new home:

Repository: https://github.com/xsignon-secure/E2E
Releases: https://github.com/xsignon-secure/E2E/releases
MCP Registry name: io.github.xsignon-secure/E2E
playwright-e2e-mcp is, and stays, fully open source and free under the MIT license.
